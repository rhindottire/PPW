TUGAS MATA KULIAH EKSTRAKSI INFORMASI

UJICOBA DEEP LEARNING IE

A. MAKSUD DAN TUJUAN
    Mahasiswa melakukan proses ujicoba code Deep Learning IE
    Mahasiswa memahami aplikasi Deep Learning IE dan code di python
    Mahasiswa memahami tahapan dan proses pada masing-masing Deep Learning IE
    Mahasiswa memahami resource library Deep Learning IE pyhton yang bisa digunakan

B. TAHAPAN TUGAS
   1. Silahkan pelajari code Deep Learning IE yang disediakan pada share folder
      https://drive.google.com/drive/folders/1c2Ou9fCnG4stJRJbobDy5VSUxCMNM8XV
   2. Lakukan ujicoba untuk menjalankan code dan pastikan code bisa dijalankan dengan baik sampai mendapatkan output/hasil ekstraksi.
   3. Simpan bukti telah berhasil menjalankan code sampai terlihat output dalam file pdf IE-coba-DL1-nim.pdf (tanpa CBOW) dan IE-coba-DL2-nim.pdf (dengan CBOW).
   4. Buat Dataset sesuai format Deep Learning menggunakan dokumen putusan hasil scrapping pada tugas sebelumnya sesuai PN yang dipilih.
   5. Modifikasi Code dua pendekatan Deep Learning untuk dapat menjalankan proses IE menggunakan dataset sendiri. Modifikasi lain bisa ditambahkan jika diperlukan. Termasuk diijinkan untuk menambah fitur lain.
   6. Lakukan proses ekstraksi informasi menggunakan Deep Learning sehingga input data putusan dapat menghasilkan output berupa informasi entitas yang dicari.
   7. Buat file PDF untuk memperlihatkan proses menjalankan code Deep Learning IE beserta hasil dan berikan catatan seperlunya pada code. Jika pakai browser Opera bisa memilih menu page save as pdf. Sedangkan pada browser yang lain bisa pakai menu print dan pilih bentuk pdf. Beri nama file yang disimpan dengan IE-modif-DL-nim.pdf
   8. Kumpulkan tugas dalam bentuk file IE-coba-DL1-nim.pdf, IE-coba-DL2-nim.pdf, dan IE-modif-DL-nim.pdf, sesuai batas waktu yang sudah ditentukan di GCR.

C. INDICATOR PENILAIAN
   1. Berhasil menunjukkan bukti sudah dapat menjalankan code DL1 dan DL2 dengan baik.
   2. Membuat dataset dokumen putusan sesuai PN yang dipilih sebelumnya.
   3. Membuat modifikasi minimal dataset sendiri atau menambahkan modifikasi lainnya.
   4. Jika masih terjadi 2 atau lebih mahasiswa dengan hasil scraping yang sama, maka mohon maaf nilai tidak akan diberikan.
