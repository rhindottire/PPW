# TUGAS MATA KULIAH EKSTRAKSI INFORMASI

## UJICOBA MACHINE LEARNING IE SEDERHANA

### A. MAKSUD DAN TUJUAN

- Mahasiswa melakukan proses ujicoba code Machine Learning IE
- Mahasiswa memahami aplikasi Machine Learning IE dan code di python
- Mahasiswa memahami tahapan dan proses pada masing-masing Machine Learning IE
- Mahasiswa memahami resource library Machine Learning IE pyhton yang bisa digunakan

### B. TAHAPAN TUGAS

1. Silahkan pelajari code Machine Learning IE yang disediakan baik pada folder ML1 maupun ML2.
   ML1 adalah code ML yang sederhana dan menggunakan kombinasi fitur (word, POS, Prev, Next),
   sedangkan ML2 ada tambahan fitur word shape dan juga tampilan/UI:
   https://drive.google.com/drive/folders/16GKudbRKcmUgMpRpaKVKUk1sSGyT9P1n?usp=drive_link
2. Lakukan ujicoba untuk menjalankan code dan pastikan code bisa dijalankan dengan baik sampai
   mendapatkan output/hasil ekstraksi.
3. Simpan bukti telah berhasil menjalankan code sampai terlihat output dalam file pdf
   `IE-coba-ML1-nim.pdf` dan `IE-coba-ML2-nim.pdf`.
4. Buat Dataset sesuai format contoh menggunakan dokumen putusan hasil scrapping pada tugas
   sebelumnya sesuai PN yang dipilih.
5. Modifikasi Code (salah satu dari ML1 atau ML2) untuk dapat menjalankan proses IE menggunakan
   dataset sendiri. Modifikasi lain bisa ditambahkan jika diperlukan. Termasuk diijinkan untuk
   menambah fitur lain.
6. Lakukan proses ekstraksi informasi menggunakan Machine Learning sehingga input data putusan
   dapat menghasilkan output berupa informasi entitas yang dicari.
7. Buat file PDF untuk memperlihatkan proses menjalankan code Machine Learning IE beserta hasil dan
   berikan catatan seperlunya pada code. Jika pakai browser Opera bisa memilih menu page → save as
   pdf. Sedangkan pada browser yang lain bisa pakai menu print dan pilih bentuk pdf. Beri nama file
   yang disimpan dengan `IE-modif-ML-nim.pdf`.
8. Kumpulkan tugas dalam bentuk file `IE-coba-ML1-nim.pdf`, `IE-coba-ML2-nim.pdf`, dan
   `IE-modif-ML-nim.pdf`, sesuai batas waktu yang sudah ditentukan di GCR.

### C. INDICATOR PENILAIAN

1. Berhasil menunjukkan bukti sudah dapat menjalankan code ML1 dan ML2 dengan baik.
2. Membuat dataset dokumen putusan sesuai PN yang dipilih sebelumnya.
3. Membuat modifikasi minimal dataset sendiri atau menambahkan fitur maupun modifikasi lainnya.
4. Jika masih terjadi 2 atau lebih mahasiswa dengan hasil scraping yang sama, maka mohon maaf nilai
   tidak akan diberikan.

### D. PEMBAGIAN RENTANG NILAI

maka akan diberikan Nilai:
